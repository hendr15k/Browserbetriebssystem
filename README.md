# Browserbetriebssystem

Ein umfangreiches Betriebssystem, das vollständig im Browser läuft. Es wurde mit HTML, CSS und JavaScript erstellt und bietet eine Vielzahl von Anwendungen und Funktionen.

## Features

### System
- **Desktop-Umgebung**: Drag & Drop Icons, anpassbares Hintergrundbild.
- **Taskleiste**: Startmenü, Uhrzeit (mit Kalender-Tooltip), "Desktop anzeigen"-Button.
- **Fenstermanagement**: Verschieben, Minimieren, Maximieren, Schließen, Fokussieren.
- **Einstellungen**: Anpassung von Theme-Farben und Hintergrundbildern.
- **Task Manager**: Überwachung laufender Prozesse und simulierter CPU/RAM-Auslastung.
- **Datei-Explorer**: Navigieren, Erstellen von Ordnern, Umbenennen, Löschen und Öffnen von Dateien.
- **Terminal**: Kommandozeile mit Befehlen wie `ls`, `cd`, `mkdir`, `cp`, `mv` und mehr.

### Anwendungen
- **Notepad**: Texteditor mit Zeilen-/Spaltenanzeige sowie Speichern/Laden.
- **Markdown Viewer**: Anzeige von Markdown-Dateien (.md).
- **Web Browser**: Simulierter Browser mit Verlauf und Navigation.
- **Taschenrechner**: Standard- und wissenschaftliche Funktionen.
- **Uhr**: Weltuhr, Stoppuhr und Timer.
- **Kalender**: Monatsansicht mit Navigation.
- **Unit Converter**: Umrechner für Länge, Gewicht und Temperatur.
- **Sticky Notes**: Haftnotizen auf dem Desktop, die gespeichert werden.
- **Speak**: Text-zu-Sprache Ausgabe.
- **Kamera**: Zugriff auf die Webcam für Fotos.

### Multimedia
- **Paint**: Zeichenprogramm mit Pinsel, Füllen und Farbauswahl.
- **Music Player**: Abspielen von Audiodateien.
- **Video Player**: Abspielen von Videodateien.

### Spiele
- **Snake**: Klassisches Snake-Spiel mit Highscore.
- **Tetris**: Vollständiges Tetris-Spiel.
- **Minesweeper**: Minesweeper mit Timer und Flaggen.
- **Tic Tac Toe**: Einfaches Tic Tac Toe gegen einen Freund (Hotseat).
- **Memory**: Karten-Aufdeckspiel.
