# Browserbetriebssystem

Ein einfaches Betriebssystem, das im Browser läuft. Es wurde mit HTML, CSS und JavaScript erstellt und benötigt keine Installation.

## Features
- **Desktop-Umgebung**: Drag-and-Drop Icons, anpassbarer Hintergrund.
- **Taskleiste**: Startmenü mit Suche, Uhrzeit/Datum, 'Desktop anzeigen'-Button.
- **Fenstermanagement**: Verschieben, Minimieren, Maximieren, Schließen, Fokussieren.
- **Anwendungen**:
    - **Produktivität**: Terminal, Notepad, Datei-Explorer, Rechner, Kalender, Uhr (mit Stoppuhr/Timer), Web Browser, Einheitenumrechner, Haftnotizen (Sticky Notes).
    - **Multimedia**: Paint, Kamera, Musik-Player, Video-Player, Sprachausgabe (Speak).
    - **Spiele**: Snake, Tetris, Minesweeper, Tic Tac Toe, Memory, Solitaire.
    - **System**: Einstellungen (Themes), Task-Manager, Info (About).
