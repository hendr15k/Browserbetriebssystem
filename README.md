# Browserbetriebssystem

Ein einfaches Betriebssystem, das im Browser läuft. Es wurde mit HTML, CSS und JavaScript erstellt und benötigt keine Installation.

## Features
- **Desktop-Umgebung**: Desktop-Icons, anpassbarer Hintergrund, Kontextmenü
- **Fenstermanagement**: Verschieben, Größe ändern, Minimieren, Maximieren, Schließen, Fokussieren
- **Taskleiste**: Startmenü mit Suche, Uhrzeit (inkl. Weltuhr, Stoppuhr, Timer), "Desktop anzeigen" Button
- **System-Apps**:
  - Terminal
  - File Explorer (virtuelles Dateisystem)
  - Settings (Hintergrund, Designfarbe)
  - Task Manager
- **Produktivität & Tools**:
  - Notepad
  - Markdown Editor & Viewer
  - Calculator (Standard & Wissenschaftlich)
  - Unit Converter
  - Sticky Notes
  - Calendar
  - Clock
  - Speak (Text-to-Speech)
  - Camera
- **Multimedia**:
  - Web Browser
  - Music Player
  - Video Player
- **Spiele**:
  - Snake
  - Minesweeper
  - Tic Tac Toe
  - Tetris
  - Memory
  - Solitaire
  - Pong
  - 2048
  - Sudoku
