# Browserbetriebssystem

Ein einfaches Betriebssystem, das im Browser läuft. Es wurde mit HTML, CSS und JavaScript erstellt und benötigt keine Installation.

## Features

### Allgemeine Funktionen
- **Desktop-Umgebung**: Interaktiver Desktop mit Icons und anpassbarem Hintergrund.
- **Taskleiste**: Startmenü, Taskleiste für geöffnete Fenster und Uhrzeitanzeige.
- **Fenstermanagement**: Fenster können verschoben, minimiert, maximiert und geschlossen werden.
- **Speicherung**: Änderungen (z.B. Dateien, Einstellungen, Highscores) werden im `localStorage` des Browsers gespeichert.

### Anwendungen
- **Terminal**: Kommandozeile mit Befehlen wie `ls`, `cd`, `echo`, `cat`, `date` und mehr.
- **Notepad**: Texteditor zum Erstellen, Speichern und Öffnen von Textdateien. Unterstützt Download und lokalen Dateiupload.
- **Datei-Explorer**: Übersicht über das virtuelle Dateisystem mit Möglichkeiten zum Umbenennen und Löschen von Dateien.
- **Rechner**: Vollständiger Taschenrechner mit wissenschaftlichen Funktionen.
- **Paint**: Zeichenprogramm mit verschiedenen Farben, Pinselgrößen und Speicherfunktionen.
- **Kamera**: Zugriff auf die Webcam, um Fotos aufzunehmen und im System zu speichern.
- **Spiele**:
  - **Snake**: Der Klassiker mit Highscore-Speicherung.
  - **Tic Tac Toe**: Einfaches Spiel gegen einen lokalen Gegner.
- **Einstellungen**: Ändern des Desktop-Hintergrunds und Zurücksetzen des Systems.
- **Sprachausgabe (Speak)**: Text-zu-Sprache Funktion.
- **Info (About)**: Informationen über das System.
