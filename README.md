# Browserbetriebssystem

Ein einfaches Betriebssystem, das im Browser läuft. Es wurde mit HTML, CSS und JavaScript erstellt und benötigt keine Installation.

## Features
- Desktop-Umgebung mit Icons
- Taskleiste mit Startmenü und Uhr
- Fenstermanagement (Verschieben, Schließen, Fokussieren)
- Funktionierendes Terminal
- Notepad und About Anwendungen
